# Social Media App Design System

## Introduction
This design system is inspired by the minimal, clean aesthetics of Shadcn UI, focusing on a dark mode interface that prioritizes content and user experience.

## Colors
The color palette is built around a dark mode theme with carefully selected contrast ratios for readability and visual hierarchy.

### Main Colors
- **Background**: `#09090B` - The primary dark background color
- **Foreground**: `#FAFAFA` - Primary text color with high contrast

### UI Elements
- **Card**: `#18181B` - Slightly lighter than background for card elements
- **Border**: `#27272A` - Subtle borders for separation
- **Muted**: `#27272A` - Background for secondary elements
- **Muted Foreground**: `#A1A1AA` - Text color for secondary information

### Text Variations
- **Primary Text**: `#FAFAFA` - High contrast text
- **Secondary Text**: `#A1A1AA` - Less prominent text
- **Subtle Text**: `#71717A` - For tertiary information

### Status Colors
- **Destructive**: `#EF4444` - For critical actions like delete
- **Success**: `#10B981` - For positive actions or confirmations
- **Warning**: `#F59E0B` - For alerts and warnings
- **Info**: `#3B82F6` - For informational elements

## Typography
We use the Poppins font family throughout the application with specific weights:
- **Bold**: For headings and emphasis
- **SemiBold**: For sub-headings and important elements
- **Medium**: For buttons and interactive elements
- **Regular**: For body text and general content

## Components

### Buttons
Our buttons follow a minimal design with subtle visual cues:

#### Variants
- **Default**: Solid white button with dark text
- **Outline**: Transparent with border
- **Ghost**: Text-only button with no background
- **Destructive**: Red background for critical actions
- **Link**: Text-only with underline

#### Sizes
- **Small**: Compact for tight spaces
- **Medium**: Standard size for most uses
- **Large**: For primary actions or emphasis

### Profile Elements
- **Profile Avatar**: Circular with subtle border
- **Stats Display**: Clean numerical presentation with labels
- **Bio Text**: Subtle coloring with appropriate line height
- **Action Buttons**: Primary action (Redeem) as a centered button
- **Profile Menu**: 3-dot menu in top right corner for Edit Profile and Logout options

### Tabs
- **Tab Bar**: Subtle borders with active indicator
- **Tab Items**: Icon and text with state changes
- **Active Indicator**: Bottom border highlight

### Menu/Dropdown
- **Dropdown Menu**: Semi-transparent overlay with card for options
- **Menu Items**: Icon + text with appropriate spacing and dividers
- **Menu Animation**: Fade animation for smooth appearance

## Layout Principles
- **Consistent Spacing**: Maintain 16px base spacing
- **Clean Alignment**: Elements align to a consistent grid
- **Minimal Dividers**: Use spacing rather than lines where possible
- **Content Focus**: Reduce UI chrome to highlight user content

## Interactive States
- **Default**: Standard appearance
- **Hover**: Subtle brightness change (web) or feedback (mobile)
- **Active/Pressed**: Visual depression or highlight
- **Disabled**: Reduced opacity with no interaction

## Animation
- Subtle, quick transitions (150-250ms)
- Ease-in-out timing functions
- Minimal but purposeful motion

---

This design system aims to create a cohesive, minimal interface that puts content first while maintaining excellent usability and accessibility.
